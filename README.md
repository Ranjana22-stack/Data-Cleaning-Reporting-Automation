# Automated Data Cleaning & Reporting System

## Overview

This project automates data cleaning and reporting workflows using Python and Power BI.

## Features

* Missing value handling
* Duplicate removal
* Data standardization
* Automated report generation
* Visual analytics dashboard

## Technologies Used

* Python
* Pandas
* Matplotlib
* OpenPyXL
* Power BI

## Output Files

* cleaned_data.csv
* report.xlsx
* math_chart.png
